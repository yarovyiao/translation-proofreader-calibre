First public release of Translation Proofreader for Calibre.

Download **Translation-Proofreader-0.11.15.zip** under Assets and install it via **Calibre → Preferences → Plugins → Load plugin from file**. Do not install GitHub's automatic **Source code** ZIP.

This version adds an optional experimental polishing section, clearer review actions, proofreading-pass tags, and initial interface translations for six languages. See the [installation guide](https://github.com/yarovyiao/translation-proofreader-calibre/blob/main/docs/USER_GUIDE.md) and [full changelog](https://github.com/yarovyiao/translation-proofreader-calibre/blob/main/CHANGELOG.md).

Requires Calibre 7.0+. Tested with Calibre 9.12 on Windows; other operating systems have not been verified to the same extent. Bring your own AI provider or local model. Review all AI output before use.
